# 前言

> 🎯 *“这里大概分析了从 39.4～41.2 中间不同版本，从 41.1 开始算法发生了一些改动。”*

## 为什么会有这本笔记

这是一份**学习笔记**，而不是一篇新论文。

原文《某音App风控参数分析》用一篇长文压缩了大量信息：三层风控、设备指纹、注册链路、七神签名头、Medusa 的 field13、Perseus 的 FL 链、Gorgon 的请求绑定……信息密度很高，但长文不适合反复查阅，也不方便按主题补充。

因此，本项目参考 [agent_learning](https://github.com/Haozhe-Xing/agent_learning) 的构建方式，把原文拆成：

- **分篇**：风控体系 → 身份指纹 → 注册流程 → 核心参数 → 复盘延伸；
- **分章**：每章一个主题，章内再按小节拆分；
- **双语**：中文源 + 英文镜像，术语保持一致；
- **可继续补充**：原文缺图、语义不明、需要实测的地方，都留下明确标记和问题清单。

## 整理原则

1. **忠实抄录**：技术事实、参数名、表格、示例向量尽量保持原文，不改写结论。
2. **不臆造**：原文中“冒号后没有内容”的位置，标注为 <span class="badge gap">原文缺图</span>，不靠猜测补全。
3. **区分来源**：哪些是原文结论，哪些是笔记推导，哪些是待验证问题，分别标注。
4. **只谈原理，不给操作**：不提供批量注册、养号、绕过风控的步骤；动态实验只在授权环境中进行。

## 原文覆盖范围

| 维度 | 范围 |
|---|---|
| App 版本 | 39.4 ～ 41.2 |
| 重点版本 | 41.1 / 41.2（算法改动分界） |
| 核心组件 | MSSDK、Medusa、Perseus、Gorgon、SDI、TicketGuard、Badger |
| 网络栈 | ttNet / Cronet、TLS 指纹、HTTP/2 |

原文对 39.4～41.0 着墨较少，重点在 **41.1 起的改动**；本笔记保留这一偏向，并把版本差异单独成节。
