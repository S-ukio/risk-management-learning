# 5.3 合规、伦理与研究边界

> 🎯 *“能理解”不等于“可以滥用”。*

## 为什么这一节必须存在

这份笔记分析的是真实平台的风控参数。它天然具有双用途：

- **防御视角**：理解平台如何识别异常设备、如何设计签名与状态机；
- **滥用视角**：绕过风控、批量注册、刷量、欺诈。

本笔记只服务于前者。以下边界不是“免责声明套话”，而是研究能否持续、合法、负责任的前提。

## 四条底线

### 1. 只在授权环境中实验

- 你拥有或获得明确书面授权的设备、账号、App、网络；
- 企业内部的合规测试、漏洞赏金项目、CTF、教学实验；
- 不针对真实用户的账号、设备或数据。

### 2. 不做批量滥用

- 不批量注册账号；
- 不养号、刷量、刷评论、刷下单；
- 不规避平台计费、风控或内容审核；
- 不把“85% 成功率”当作可复制目标。

### 3. 不碰个人数据

- 不收集、存储、传播他人的个人信息；
- 不抓取通讯录、位置、设备标识等敏感数据；
- 分析样本中的 token、device_id、session_uuid 应视为敏感数据，脱敏后再引用。

### 4. 负责任披露

- 发现可被利用的安全问题，先按平台 / 厂商的披露流程报告；
- 不在公开渠道发布可直接利用的完整链路；
- 给厂商合理的修复窗口。

## 法律与条款风险

| 风险 | 说明 |
|---|---|
| 平台服务条款 | 绕过风控、批量注册通常违反 ToS，可能导致封号、民事索赔 |
| 计算机犯罪相关法律 | 未授权访问、干扰计算机信息系统可能触犯刑法 |
| 个人信息保护 | 收集、处理个人信息需有合法性基础 |
| 著作权 | 原文与技术资料的使用需尊重原作者权利 |

> ⚠️ 不同国家和地区的法律不同。本节不构成法律意见；涉及具体项目时，请咨询法务。

## 实验前检查表

在开始任何动态实验之前，逐项确认：

- [ ] 我有设备 / 账号 / 网络的明确授权；
- [ ] 实验不会影响真实用户；
- [ ] 我不会批量注册或养号；
- [ ] 我不会收集或传播个人信息；
- [ ] 样本中的标识符会脱敏；
- [ ] 我知道如何联系厂商 / 平台进行披露；
- [ ] 我了解相关的平台条款与法律风险。

## 对原文的引用边界

- 原文的技术内容版权归原作者；
- 本笔记是学习整理，默认私有；
- 不把原文内容用于商业培训、付费社群或“教程”售卖；
- 引用时注明来源，并保留原文的“仅供交流学习”声明。
