# 第一部分：风控体系

> 先建立地图，再进细节。

这一部分回答三个问题：

1. 某音的风控到底在检查什么？
2. 七个签名头分别负责什么？
3. 这些头由哪些本地 SDK 组件生成？

## 本部分包含

- [第1章 风控体系总览](./chapter_overview/README.md)
  - 1.1 三层风控模型
  - 1.2 七神签名组与明文上下文
  - 1.3 本地 SDK 组件对应关系
  - 1.4 版本演进：39.4 → 41.2

## 读完你应该能

- 用一句话解释“设备层 / 网络层 / 行为层”的分工；
- 区分“明文声明”和“签名证明”，并说出为什么两者不一致比算错签名更常见；
- 把每个签名头映射到对应的 native 库；
- 说出 41.1 前后最核心的两处算法变化。

> 💡 **建议**：这一部分不要急着记参数名，先把“三层 + 两组头 + 四个库”的关系画出来。
